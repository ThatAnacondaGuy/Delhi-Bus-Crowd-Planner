# docs/assets

Pictures used by the README, the technical note and the proposal.

| File | What it is | How it is made |
| --- | --- | --- |
| `architecture.svg`, `architecture-dark.svg` | Animated system diagram: inputs, pipeline, outputs, planner and API, screens. Data packets travel along the arrows and each box lights up in pipeline order. | `python docs/make_diagrams.py` (light and dark variants from one script). The README picks one with `<picture>`. |
| `how-it-works.svg`, `how-it-works-dark.svg` | Animated five-step story of one made-up ticket becoming a crowding level. | `python docs/make_diagrams.py`. Contains no data numbers. |
| `fig-levels-by-hour.svg` | Weekday crowding level by hour, share of bus-km. | `python docs/make_figures.py`, from `data/processed/coverage.csv`. |
| `fig-trips-ran-by-hour.svg` | Share of scheduled trips that ran, by hour (GPS). | `python docs/make_figures.py`, from `data/processed/planner/gps_rho_fill.parquet`. |
| `fig-travel-time-factor.svg` | Observed run time against the timetable, DTC and cluster, by hour. | `python docs/make_figures.py`, from `data/processed/planner/runtime_factors.parquet`. |
| `fig-load-factor-bracket.svg` | Model load factor and full allocation against the published band. | `python docs/make_figures.py`, from `validation_report.json`. |
| `fig-corridor-check.svg` | Corridor check against its chance baseline. | `python docs/make_figures.py`, from `validation_report.json`. |
| `app-commuter-cp-to-anand-vihar.png`, `app-commuter-leave-later-mandi-house.png` | Commuter screen, 390 x 844 at 2x, on the full data. | Local server on the full data, Chrome in phone emulation (device scale 2), Connaught Place to ISBT Anand Vihar and Mandi House to Laxmi Nagar, weekday 18:00. |
| `app-operator-view.png` | Operator view, 1440 x 900 at 2x. | Same local server, `/operator`. |

Notes

- Every number in a figure title or label is computed by `docs/make_figures.py` from the pipeline outputs; nothing is typed by hand. Rerun it after rebuilding the data. Without `data/processed` it prints a message and writes nothing.
- The SVGs are plain XML with CSS only (no scripts), so the animation also runs when GitHub shows them through `<img>`. With "reduce motion" switched on in the operating system they show as still pictures.
- The figures carry their own light background, so they read on light and dark pages.
- Screenshots are regenerated by starting `uvicorn src.api.main:app` on the full data and capturing the same two URLs; they are not part of the test suite.
